# Changelog

## 1.0.0

- First public release.
- Bionic Reading for prose in `.tex` files; commands, math, comments, verbatim blocks and non-prose arguments are skipped.
- Five Morandi palettes with separate light and dark theme tones.
- Status bar menu with live preview for palette, colour depth, saturation, contrast, colour cycle and bold weight.
- English and Simplified Chinese user interface.
